# NXTFLIX

A responsive movie discovery application built using React and Vite.

## Features

- User Authentication
- Protected Routes
- Hero Banner
- Trending Now Carousel
- Fresh Releases Carousel
- Search Movies
- Genre Filter
- Movie Details Page
- Watch Later
- Responsive Design
- 404 Not Found Page

## Tech Stack

- React
- React Router DOM
- Vite
- CSS
- js-cookie

## Installation

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
